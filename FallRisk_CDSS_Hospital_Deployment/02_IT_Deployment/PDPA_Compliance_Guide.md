# มาตรการคุ้มครองข้อมูลส่วนบุคคลและข้อมูลสุขภาพ (PDPA Compliance)

1. **การควบคุมการเข้าถึง (Access Control):** มีระบบ Authentication กำหนดสิทธิ์ผู้ใช้ตามบทบาท (Role-based Access Control: RBAC)
2. **การปกปิดตัวตน (Data Minimization & Pseudonymization):** การประมวลผลของโมเดล AI ภายในใช้เฉพาะรหัสประจำตัวผู้ป่วย (HN) และตัวแปรทางคลินิก ไม่มีการเก็บเลขบัตรประชาชน 13 หลัก
3. **การทำงานภายในเครือข่ายโรงพยาบาล (Air-Gapped / On-Premise):** ระบบทำงานแบบ 100% On-Premise ภายในเครือข่าย LAN/Intranet ของโรงพยาบาล ไม่มีการส่งข้อมูลผู้ป่วยออกสู่ภายนอก
4. **การบันทึกประวัติการใช้งาน (Audit Log):** มีการบันทึก Log การเข้าดูข้อมูลของผู้ใช้งานเพื่อการตรวจสอบย้อนหลัง
