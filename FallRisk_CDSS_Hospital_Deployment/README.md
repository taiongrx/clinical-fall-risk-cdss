# Clinical Fall Risk CDSS - Deployment Package
Hospital Delivery Package for Clinical Decision Support System (Fall Risk Prediction in Older Adults)
Saiburi Crown Prince Hospital, Pattani Province

## Package Structure
- `01_Clinical_Manuals`: Clinical guides, FRIDs reference list, and deprescribing protocol
- `02_IT_Deployment`: Docker scripts, Read-Only SQL query for HOSxP, and IT runbook
- `03_Software_and_AI_Engine`: FastAPI backend, compiled frontend, and LightGBM AI model

Developed by: Kritsada Poh-jeen, Pharm.D. (Saiburi Crown Prince Hospital)
