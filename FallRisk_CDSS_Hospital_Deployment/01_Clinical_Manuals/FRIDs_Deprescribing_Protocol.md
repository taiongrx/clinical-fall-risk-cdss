# แนวทางการทบทวนและปรับลดยากลุ่มเสี่ยงหกล้ม (FRIDs Deprescribing Protocol)
โรงพยาบาลสมเด็จพระยุพราชสายบุรี ร่วมกับโรงพยาบาลเครือข่าย

## 1. วัตถุประสงค์
1. เพื่อป้องกันอุบัติการณ์การพลัดตกหกล้มในผู้ป่วยนอกสูงอายุ (>= 60 ปี)
2. เพื่อสนับสนุนกระบวนการบริบาลทางเภสัชกรรมเชิงรุกในคลินิกโรคเรื้อรัง (NCD Clinic) และคลินิกผู้สูงอายุ
3. เพื่อลดปัญหาจากการใช้ยาที่ไม่เหมาะสม (Potentially Inappropriate Medications: PIMs) ตามเกณฑ์ Beers Criteria 2023 และ STOPP-Fall 2019

## 2. ขั้นตอนการปฏิบัติการทางคลินิก (Clinical Workflow)
1. **คัดกรองอัตโนมัติ (AI Triage):** ระบบ Clinical CDSS จะทำการดึงข้อมูลผู้ป่วยนอกสูงอายุที่มารับบริการ และคำนวณความเสี่ยงหกล้มด้วยแบบจำลอง Machine Learning (BalancedBagging LightGBM)
2. **ส่งสัญญาณเตือน (Alert):** เมื่อพบผู้ป่วยที่มีความเสี่ยงสูง (High Risk / Very High Risk) ระบบจะแสดงแถบสีแดง/ส้ม พร้อมระบุรายการยาเสี่ยง FRIDs ที่ผู้ป่วยกำลังได้รับ
3. **เภสัชกรประเมินและให้คำแนะนำ (Pharmacist Intervention):**
   - ตรวจสอบข้อบ่งใช้ ความจำเป็น และขนาดยาปัจจุบัน
   - บันทึกคำแนะนำ Deprescribing ในระบบเวชระเบียน พร้อมเสนอทางเลือกยาที่ปลอดภัยกว่าต่อแพทย์ผู้ตรวจ
4. **แพทย์พิจารณาปรับคำสั่งยา (Physician Decision):**
   - แพทย์พิจารณาหยุดยา (Discontinue), ลดยา (Dose Reduction) หรือเปลี่ยนกลุ่มยา (Switching)
5. **ติดตามผล (Monitoring):** ติดตามอาการทางคลินิก อาการถอนยา และอุบัติการณ์การหกล้มในการนัดตรวจครั้งถัดไป
